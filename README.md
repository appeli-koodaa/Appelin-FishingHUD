# Appelin FishingHUD

Fishing overlay for livestreams.

## FishingHUD 2.0

Versio 2.0 lisää lajikohtaisen TOP 5 -pituusnäkymän hauelle, kuhalle ja ahvenelle. Adminissa jokaisen lajin TOP 5 voidaan kytkeä erikseen näkyviin, syöttää viisi pituutta ja tallentaa Firebaseen. Overlay järjestää pituudet suurimmasta pienimpään ja laskee yhteismitan automaattisesti. Overlayn visuaalisuutta on samalla modernisoitu kevyillä valkoreunaisilla pituuslaatikoilla ja tummalla läpikuultavalla alapalkilla.


## FishingHUD 2.0.2 test

- Clear 1.–5. longest labels in admin.
